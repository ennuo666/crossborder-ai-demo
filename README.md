# 跨境 AI 工作台 Demo

这是根据 `DOCS` 产品设计文档制作的中文前端原型，当前使用本地模拟数据，不包含真实后端、模型调用或发布接口。

## 本地运行

要求：Node.js 18 或更高版本。

```powershell
node preview-server.cjs
```

然后打开 <http://127.0.0.1:4173>。

## 可体验流程

- 创建商品：三步表单创建一个商品项目
- 竞品研究：查看价格、卖点、痛点和关键词机会
- Listing 文案：编辑标题、五点描述和关键词，生成新版本
- 商品素材：选择主图并模拟生成素材
- 商品页：查看独立站商品页预览并模拟发布
- SEO 优化：查看分数、问题清单和修复入口
- AI Copilot：围绕当前商品发送问题并查看模拟回复
